How to connect your Telegram bot

1. Create a bot via @BotFather on Telegram and copy your token.

2. Run the Python bot script provided in the documentation below.

3. Send messages to your bot in this format:

150.00 food 89.90 transport 320 rent

4. The bot replies with a confirmation and this dashboard updates automatically.
